# Lamha-Custom-E-Commerce-Storefront-for-an-Occasion
Custom-built e-commerce storefront for a Pakistani occasion-wear brand — a self-contained HTML site with product carousels, cart drawer, multi-step checkout, COD/Easypaisa/JazzCash payment options, auto-generated order confirmations, and a custom nude-and-red brand palette. Built entirely from scratch, no frameworks.
